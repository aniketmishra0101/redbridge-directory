# Redbridge Directory — Pre-Launch Landing Page

An official, responsive, high-conversion pre-launch landing page for the **Redbridge Directory**, backed by the **Redbridge Chamber of Commerce (RCC)**.

---

## 1. Quick Start

### Option A: Direct Browser Preview (Zero Dependencies)
Open `index.html` directly in any modern web browser:
```bash
open index.html
```

### Option B: Local HTTP Preview Server
Run the built-in, zero-dependency Node.js HTTP server:
```bash
node server.js
# Or via npm:
npm start
```
Then visit [http://localhost:3000](http://localhost:3000) in your browser.

### Option C: Run Verification Tests
Verify all 18 acceptance checklist requirements:
```bash
npm test
```
